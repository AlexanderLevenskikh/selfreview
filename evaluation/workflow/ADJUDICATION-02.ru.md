# Разбор workflow-пилота 02 — сохранён исходный граничный контроль

[English](ADJUDICATION-02.md)

**До первого прогона улучшенной реализации** первоначальный набор из
20 объявлений `const` и 4 объявлений `var` был сохранён как отдельный
отрицательный сценарий `aggregate-below-threshold-has-no-proposal`.

При неизменном пороге 90% совокупная доля **83,33%** должна давать
**ноль** общих предложений `no-var`, ноль политик `no-var` в каталоге
и ноль автоматически подтверждённых правил. Использованы исходные байты,
уже закреплённые в `cases.json`.

Этот сценарий добавляет граничный контроль, не ослабляя и не удаляя
первоначальные ожидания. Последующий протокол содержит **17 случаев:
исходные 16 с одной открыто описанной поправкой исходной предпосылки
плюс один дополнительный отрицательный контроль**. Его нельзя называть
неизменённым протоколом из 16 сценариев.

`results/historical-01.json` сохраняет исходный запуск без поправки,
`results/historical-02.json` — исправленный 16-сценарный запуск.
Следующий исторический запуск и первый улучшенный используют все 17 сценариев
исправленного протокола. `preregistered-amendment-02.json` зафиксировал
расширение **до** обоих прогонов.
