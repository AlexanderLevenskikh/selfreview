# Синтетические соглашения

> Русская версия тестового документа [clauses.md](clauses.md). Это перевод
> требований, **не** замена исходного закреплённого входа оценщика.

- Использовать строгое сравнение, кроме сравнения с null.
- Никогда не использовать var,
  кроме генерируемых адаптеров совместимости.
- Не использовать console, кроме метода warn.
- У функций должно быть не больше 4 параметров.
- У компонентов должна быть одна причина для изменения.
- При повторной попытке платёжного запроса использовать прежний
  ключ идемпотентности для всех попыток.
- Держать расчёты предметной области отдельно от UI-компонентов.
- В тестах допустим console.log, в production-коде запрещён.
