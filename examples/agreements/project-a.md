# Договорённости проекта A

- Не использовать var.
- Не использовать console.
- Компоненты не более 120 строк.
- Разделяйте загрузку данных и представление, если у них разные причины изменения.

Оговорки и бизнес-контекст обсуждаются отдельно; частота приёма в старом коде не делает его соглашением.
